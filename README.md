# 花瓣网 - 原生右键 + 原图下载 + 商用标签

> 作者：liteyais ｜ 版本：v1.0.3 ｜ 协议：MIT
> 仓库：https://github.com/liteyais/huaban-userscripts

一款让花瓣网更好用的小工具，装上后自动拥有以下 4 个功能：

## 功能介绍

**1. 恢复浏览器原生右键菜单**
以前在花瓣网上点鼠标右键，弹出的是花瓣网自己的菜单。装上本脚本后，点右键直接显示电脑浏览器的原生菜单，和其他网站的操作一样。可在脚本菜单【设置】中随时关闭。

**2. 商用素材自动标记**
花瓣网上标注为“版权素材”、带商用授权的图片，会自动加上红色描边，并在图片上显示红色“商用”标签，一眼就能认出哪些图片可用于商用。

**3. 悬停一键下载原图**
鼠标移到任意图片上，图片上会出现绿色【下载】按钮，点击即可下载最清晰的原图，详情页的大图也支持。

**4. 设置开关**
点击浏览器工具栏的脚本菜单 →【设置】，可随时打开或关闭“原生右键菜单”功能，修改后立即生效，无需刷新页面。

## 安装使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展；
2. 打开 [huaban-userscripts.js](https://raw.githubusercontent.com/liteyais/huaban-userscripts/main/huaban-userscripts.js)，Tampermonkey 会提示安装；
3. 打开花瓣网任意页面即可使用；设置开关位于脚本下拉菜单 →【设置】。
