# 花瓣网 - 原生右键 + 原图下载 + 商用标签

> 作者：liteyais ｜ 版本：v1.0.3 ｜ 协议：MIT
> 仓库：https://github.com/liteyais/huaban-userscripts

一款用于花瓣网（huaban.com）的 Tampermonkey 用户脚本，集三个功能于一体，全部在图片上以清晰的视觉反馈呈现。

## 功能介绍

**1. 恢复浏览器原生右键菜单**
花瓣网自带自定义右键菜单（按下右键即弹出）。本脚本在捕获阶段拦截站点监听器，并兜底隐藏站点菜单浮层，恢复浏览器/系统原生右键菜单，不影响浏览器扩展接管右键。可在脚本下拉菜单【设置】中实时开关。

**2. 商用素材自动标记**
自动识别花瓣网商用素材：列表/瀑布流卡片上的“版权素材”徽标、详情页主图的授权标识（商用无忧 / 官方自营 / 已获得…授权 / 需替换字体）、以及“商用素材”区块内的缩略图。命中后在图片上叠加 **3px 红色描边**，并在图片中央偏上显示 **胶囊形“商用”标签**（红底红边、白字）。

**3. 悬停一键下载原图**
鼠标经过任意缩略图、以及详情页主图（`#pin_detail` 内的大图）时，图片中央偏下显示 **胶囊形绿色【下载】按钮**。点击直接下载**原始 master 文件**（与详情页大图“右键 → 存储为”一致，最清晰、无 CDN 二次压缩），并自动从 `_fw1200webp → _fw960webp → _fw480webp → _fw240webp` 依次回退，确保任何素材都能拿到。

**4. 脚本下拉菜单设置**
通过油猴菜单（脚本下拉菜单）中的【设置】打开设置弹框，弹框内含【开启原生右键菜单】开关，实时切换、立即生效，无需刷新页面。设置状态通过 localStorage 持久化（键名前缀 `hb_`，与站点互不冲突）。

## 安装使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展；
2. 打开 [huaban-userscripts.js](https://raw.githubusercontent.com/liteyais/huaban-userscripts/main/huaban-userscripts.js)，Tampermonkey 会提示安装；
3. 打开花瓣网任意页面即可使用；设置开关位于脚本下拉菜单 →【设置】。
